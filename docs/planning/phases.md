# 分阶段执行计划 — 共享设备微运营平台

## 阶段 0：基础设施搭建

目标：打通从本地开发机到云端基础设施的完整链路。

| 序号 | 任务 | 产出 |
|------|------|------|
| 0.1 | 检查 Aliyun 服务器 Docker 环境 | `docker ps` 验证 |
| 0.2 | 检查本机环境（Java21/Maven/Node/pnpm） | `java -version` 等 |
| 0.3 | 编写 Docker Compose 基础设施编排 | `docker/infra-compose.yml` |
| 0.4 | 部署基础设施到 Aliyun | PostgreSQL + TimescaleDB + Redis + Mosquitto |
| 0.5 | SSH 隧道连通性验证 | PS1 脚本一键建立隧道 |
| 0.6 | 编写 PS1 进程管理脚本 | `scripts/manage.ps1`（status/start/stop/restart/log） |
| 0.7 | Spring Boot 多模块 Maven 骨架 | `pom.xml` + 子模块 |
| 0.8 | git init → main 分支 → 首次提交 | |

## 阶段 1：后端 API 全量开发 + 测试

目标：完成所有 8 大业务模块的 API 开发，并通过 MCP 浏览器全量回归测试。

| 波次 | 内容 |
|------|------|
| 波次 1 | 数据模型 + Flyway 迁移 + 通用框架（异常/分页/安全/JWT） |
| 波次 2 | 站点模块 + 设备模块全套 CRUD API |
| 波次 3 | 库存模块（SKU + 仓库库存 + 设备库存 + 阈值预测算法） |
| 波次 4 | 工单模块（全状态流转 + 权限控制） |
| 波次 5 | 派单模块（优先级计算 + 路线建议算法） |
| 波次 6 | 收益模块 + AI 助手模块 + 看板聚合 |
| 波次 7 | 设备模拟器（3+ 设备类型，并发上报） |
| 波次 8 | MCP 浏览器全量回归测试（Swagger UI + API 全覆盖） |

| 2.6 | 运营总览 + 站点详情页面 | 对接后端 API |

## 测试要求（贯穿全程）

测试是本项目最高优先级的约束。

- 后端 API 阶段：通过 Swagger UI 用 MCP 浏览器逐接口验证
- 前端阶段：每个页面元素全部点击，截图对比，网络请求抓取
- 最终验收：全量回归测试，零控制台错误，所有 API 返回 2xx
